# Demo Tiles Directory

This directory contains pre-loaded 256x256 satellite tiles curated for live hackathon demonstration of Super-Resolution Mapping (SRM).

## Contents
- `manifest.json`: JSON catalog containing metadata, regional labels, resolution specs, and tactical use-cases for each target tile.
- Procedurally generated high-resolution (2.5m/px equivalent) ground truth target tiles across 10 strategic categories:
  - Maritime / Port Facility
  - Military / Tactical Airfield
  - Urban Grid
  - Border Patrol Corridor
  - Transportation / Freeway Interchange
  - Agricultural Belt
  - River / Hydrological Feature
  - Refinery Storage Depot
  - Power Plant Infrastructure
  - Coastal Defense Outpost
